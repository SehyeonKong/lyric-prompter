# 가사 프롬프터

노래할 때 노트북·아이패드에 띄워 두는 가사 프롬프터. 설치 없이 브라우저로 연다.

## 쓰는 법
- **+ 새 곡** → 제목과 가사 붙여넣기
  - 그냥 가사: 무대에서 **자동 스크롤** (속도 −/+)
  - `[00:12.34]가사` 형식 LRC: 음악 재생과 같이 **시작** 누르면 지금 부를 줄이 노랗게, 다음 줄이 밝게 표시
- **탭으로 싱크 만들기**: 음악 틀면서 줄이 시작될 때마다 탭(스페이스) → LRC로 저장
- 무대에서 줄을 누르면 그 줄 시간으로 이동(중간부터 불러도 맞출 수 있음). 박자가 어긋나면 싱크 −/+ (0.25초씩)
- 키보드·블루투스 페이지 넘김 페달: 스페이스 시작/멈춤, ←→↑↓/PageUp·Down 이전·다음, −/+ 속도·싱크, Esc 목록
- 무대·싱크 화면에선 화면이 꺼지지 않음(Wake Lock)

## 아이패드
사파리에서 열고 **공유 → 홈 화면에 추가**. 전체 화면 앱처럼 뜨고, 사파리가 오래 안 쓴 사이트 저장소를 지우는 정책도 피할 수 있다.

## 저장
가사는 각 기기 브라우저(localStorage)에만 저장된다. 서버 없음. 기기 옮길 땐 목록 아래 **백업 내보내기/가져오기**(JSON).

## 개발
```sh
npm test      # 가사 처리 로직 테스트 (node --test)
npm start     # http://localhost:8000
```
빌드 없음. `lrc.js`(LRC 파싱·현재 줄 계산, DOM 없음) + `app.js`(화면).
