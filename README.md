# 가사 프롬프터

노래할 때 노트북·아이패드에 띄워 두는 가사 프롬프터. 설치 없이 브라우저로 연다.

## 쓰는 법
- **+ 새 곡** → 제목과 가사 붙여넣기
  - 그냥 가사: 무대에서 **자동 스크롤** (속도 −/+)
  - `[00:12.34]가사` 형식 LRC: 음악 재생과 같이 **시작** 누르면 지금 부를 줄이 노랗게, 다음 줄이 밝게 표시
- **가사 자동 찾기**: 유튜브 링크를 넣으면 영상 제목으로 무료 싱크 가사 DB([LRCLIB](https://lrclib.net))를 찾아 시간 붙은 가사를 채운다. 못 찾으면 ‘🔎 가사 찾기’에서 ‘가수 곡제목’으로 직접 검색
- **내 가사에 시간만 입히기**: 가사 칸에 내 가사(시간 없음)를 넣고 링크를 넣거나 ‘가사 찾기’ → 가사는 그대로 두고 찾은 싱크 가사의 시간만 글자 단위로 맞춰 입힌다
- **유튜브 자막으로 시간 맞추기 (맥)**: 내 가사를 복사해 두고 `npm run yt-sync -- <유튜브 링크>` → yt-dlp로 받은 한국어 자막에 맞춰 LRC를 클립보드에 복사. 직접 단 자막이 있는 영상(공식 뮤비에 많음)은 잘 맞고, 자동 자막뿐이면 노래에선 거의 못 쓴다(맞춘 줄 수를 보여주고 적으면 경고)
- **시간 확인**: 싱크 화면에서 영상에 맞춰 가사를 미리 보고, 어긋나면 노래가 새 줄을 시작할 때 탭(한참 어긋나면 ‘첫 소절 시작!’) → 전체 시간 보정. 뮤직비디오는 인트로 때문에 음원보다 늦게 시작하는 경우가 많다
- **싱크 만들기**: 음악 틀면서 줄이 시작될 때마다 탭(스페이스) → LRC로 저장. 편집에서 **유튜브 링크**를 넣으면 앱 안에서 영상을 틀고 영상 시간 기준으로 찍는다(되감아도 안 어긋남)
- **🎤 음악 따라가기 (실험)**: 싱크 만들 때 ‘음악도 기억하기’를 켜 두면 곡의 화음 흐름(크로마)을 저장해 두고, 무대에서 마이크로 밴드 소리를 들으며 지금 곡의 몇 초인지 따라간다. 밴드가 빨라지거나 느려져도(85~115%), 솔로를 늘려도 맞춰 감
  - 노트북 크롬: ‘이 탭 소리로’ 기억(공유 창에서 *탭 오디오도 공유* 켜기). 아이패드: 스피커로 틀고 ‘마이크로’
  - 무대에선 곡 시작 직전에 ‘시작’. 조용하면 기다리고, 소리가 나면 따라간다. 1절·2절처럼 똑같은 구간은 소리로 구분이 안 되니 중간부터 시작했으면 줄을 한 번 눌러 위치를 알려줄 것
  - 밴드가 원곡과 다른 키로 치면 못 따라감
- 무대에서 줄을 누르면 그 줄 시간으로 이동(중간부터 불러도 맞출 수 있음). 박자가 어긋나면 싱크 −/+ (0.25초씩)
- 키보드·블루투스 페이지 넘김 페달: 스페이스 시작/멈춤, ←→↑↓/PageUp·Down 이전·다음, −/+ 속도·싱크, Esc 목록
- 무대·싱크 화면에선 화면이 꺼지지 않음(Wake Lock)

## 아이패드
사파리에서 열고 **공유 → 홈 화면에 추가**. 전체 화면 앱처럼 뜨고, 사파리가 오래 안 쓴 사이트 저장소를 지우는 정책도 피할 수 있다.

## 저장
가사는 각 기기 브라우저(localStorage)에만 저장된다. 서버 없음. 기기 옮길 땐 목록 아래 **백업 내보내기/가져오기**(JSON).

## 개발
```sh
npm test      # 가사 처리 로직 테스트 (node --test)
npm start     # http://localhost:8000
```
빌드 없음. DOM 없는 로직은 node로 테스트한다.
- `lrc.js` LRC 파싱·현재 줄 계산
- `features.js` 소리 → 크로마, 저장용 압축 / `follow.js` 크로마로 위치 따라가기 (가짜 밴드 곡 시뮬레이션 테스트)
- `lrclib.js` 유튜브 제목 → 검색어, 가사 DB 검색(바쁨 재시도)
- `align.js` 내 가사 ↔ 시간 붙은 글(자막·싱크 가사) 글자 단위 정렬(한글은 자모로 비슷한 소리 인정) / `captions.js` json3·vtt·srt 읽기
- `tools/yt-sync.mjs` 맥용: yt-dlp로 자막 받아 내 가사에 시간 입히기
- `audio.js` 마이크·탭 소리 받기 / `youtube.js` 링크 파싱·플레이어 / `app.js` 화면
